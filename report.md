Анализ информационной системы Wildberries
1. Описание цифрового сервиса
Название: Wildberries

Ссылка: https://www.wildberries.ru/

Назначение:
Wildberries — крупнейший российский маркетплейс, предоставляющий пользователям возможность поиска, выбора и покупки товаров от множества продавцов с доставкой в пункты выдачи или курьером. Система объединяет продавцов, покупателей и логистическую инфраструктуру в единую цифровую платформу .

Целевая аудитория:

Покупатели (B2C): физические лица, ищущие товары по доступным ценам с доставкой.

Продавцы (B2B): предприниматели и компании, размещающие товары на платформе.

Партнёры логистики: пункты выдачи заказов, курьерские службы.

Основные возможности:

Поиск и фильтрация товаров по категориям, цене, бренду, рейтингу.

Просмотр карточек товаров с фото, описанием, характеристиками и отзывами.

Добавление товаров в корзину и оформление заказов.

Отслеживание статуса доставки.

Личный кабинет покупателя с историей заказов.

Партнёрский кабинет для продавцов.

Выбранный сценарий:
Поиск товара и просмотр карточки товара.

4. Описание пользовательского сценария
4.1. Название сценария
Поиск товара и просмотр карточки товара.

4.2. Последовательность выполнения
Этап 1. Пользователь открывает страницу
Браузер загружает HTML-, CSS- и JavaScript-ресурсы.

Этап 2. Пользователь вводит поисковый запрос
JavaScript обрабатывает действие и подготавливает запрос.

Этап 3. Клиентская часть взаимодействует с сервером
Отправляется запрос через API поиска с параметрами запроса.

Этап 4. Сервер обрабатывает запрос
Сервер выполняет поиск по индексу, применяет фильтры и сортировку.

Этап 5. Сервер возвращает результат
Клиент получает список найденных товаров.

Этап 6. Интерфейс отображает результаты
JavaScript обновляет интерфейс, пользователь видит список товаров.

Этап 7. Пользователь выбирает товар
Клиентская часть отправляет запрос за детальной информацией.

Этап 8. Интерфейс отображает карточку товара
Пользователь видит детальную информацию о товаре.

5.2. Взаимодействие компонентов
Пользователь выполняет действия в интерфейсе.

Браузер отображает интерфейс и выполняет клиентский код.

Клиентская часть обрабатывает действия пользователя.

При необходимости отправляется запрос через API.

Сервер обрабатывает запрос.

Сервер обращается к хранилищу данных.

Сервер возвращает результат клиенту.

Клиентская часть обновляет интерфейс.

Пользователь видит результат.

6. Вывод
В ходе лабораторной работы была проанализирована информационная система Wildberries — крупнейшего российского маркетплейса.

В рамках работы были выполнены следующие задачи:

изучено назначение, целевая аудитория и основные возможности цифрового сервиса;

проанализированы компоненты системы: страницы, элементы интерфейса и их роль в выбранном сценарии;

с помощью инструментов разработчика браузера (DevTools) исследованы HTML-структура, CSS-стили, JavaScript-файлы, загружаемые ресурсы и сетевые запросы;

описан пользовательский сценарий поиска товара и просмотра карточки;

построена архитектурная схема системы с основными компонентами и связями между ними.

Установлено, что Wildberries построен по клиент-серверной архитектуре. Клиентская часть (SPA-приложение в браузере) отвечает за отображение интерфейса и обработку действий пользователя. Серверная часть обеспечивает поиск по каталогу, хранение данных о товарах и пользователях, а также взаимодействие с внешними сервисами (CDN, API поиска и карточек).

Взаимодействие клиента и сервера осуществляется через API с использованием HTTP-запросов (Fetch/XHR), что позволяет динамически обновлять интерфейс без полной перезагрузки страницы. Данные хранятся в базе данных, поисковом индексе, кэше и объектном хранилище.

Таким образом, цель лабораторной работы достигнута: получено представление об устройстве современной информационной системы на примере реального цифрового сервиса, изучены её основные компоненты и принципы взаимодействия.
